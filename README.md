# pixel-studio

A visual, no-code development environment for 2D pixel-art point-and-click adventure games.

**Status:** Phase 0 (audit and architecture) is complete. Phase 1 (foundation) is awaiting approval.

- Open `Pixel Studio.html` in a browser to use the current pixel-art editor (the original app).
- Documentation lives in [`docs/`](docs/). Start with [the audit](docs/EXISTING_APPLICATION_AUDIT.md) and [the plan](docs/IMPLEMENTATION_PLAN.md).
